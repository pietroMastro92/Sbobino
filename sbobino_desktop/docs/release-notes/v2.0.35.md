## Sbobino 2.0.35

### Fixes

- Initial setup includes the certified Tiny assets required for Live recording; compatible local models remain available for file transcription.
- History Rename restores focus after saving or cancelling, including when the history list is regrouped.
- Live Stop diagnostics remain in logs and no longer appear in the saved transcript or TXT export.
- Pyannote cancellation finishes rollback and diagnostic persistence before reporting completion; a restored installation remains usable after a failed repair.

### New and improved

- Live preview updates arrive promptly and finalized repeated speech remains intact. A native Apple M3 900-second replay with the current context preserved all captured audio and all fixture utterances; this is a measured scenario, not a guarantee for every recording.
- Real CPU file transcription and bundled Pyannote inference are verified on standard GitHub macOS arm64, Intel and Windows x86_64 runners. Whisper and Parakeet also pass repeated service runs and an 89-second English reference test on all three architectures.

### Compatibility

- Existing settings, transcripts, models and compatible Pyannote installations are preserved.
- Live requires the certified model and a successful performance check on the device. File transcription remains available when the machine cannot sustain Live.
- Installer targets remain macOS arm64, macOS Intel and Windows x86_64. Linux validation covers declared frontend and crate support.

### Known issues

- macOS packages use ad hoc signing until Apple Developer ID and notarization credentials are configured; Gatekeeper may require manual approval. Windows installers are unsigned.
- Hosted CPU tests do not substitute for desktop microphone, GPU or screen-reader checks. Existing native hardware proofs retain their tested scope; full Intel/Windows interactive flows and screen-reader checks remain unverified.
- The measured English fixture does not certify multilingual accuracy or a general speed improvement. Pyannote interruption across different runtime versions remains unverified.
