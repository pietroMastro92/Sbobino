## Sbobino 2.0.28

### Fixes

- Corrected file-transcription progress so Whisper and Parakeet report monotonic committed work instead of remaining at zero, restarting on CPU fallback, or regressing between processing stages. (`crates/application/src/services/transcription_service.rs`)
- Kept GPU-to-CPU recovery inside the same visible job, preserving confirmed chunks and preventing diagnostic fallback messages from entering the transcript. (`crates/infrastructure/src/adapters`)
- Reworked Whisper and Parakeet live processing to detect accumulated audio backlog, surface terminal worker failures, and avoid indefinitely lagging behind the microphone. (`crates/infrastructure/src/adapters/whisper_stream.rs`, `apps/desktop/src-tauri/src/parakeet_realtime.rs`)
- Hardened Pyannote installation receipts and bundled-library validation so incompatible TorchCodec/FFmpeg assets are rejected before replacing a working installation. (`crates/infrastructure/src/lib.rs`, `apps/desktop/src-tauri/src/commands/provisioning.rs`)

### New and improved

- Added separate compute-device settings for file and live transcription. Existing file preferences are preserved, while live defaults to Auto so a CPU-safe file setting cannot accidentally make realtime transcription fall behind. (`crates/domain/src/settings.rs`, `apps/desktop/src/App.tsx`)
- Added structured progress and live diagnostics for committed/processed audio, backlog, inference duration, first preview, and finalization without exposing technical messages in transcript text. (`crates/domain/src/job.rs`, `apps/desktop/src-tauri/src/commands/realtime.rs`)
- Added reference-based ASR evaluation for word/character error rate, timestamp coverage, language transitions, and service-tag contamination, plus native Intel macOS validation on the standard public GitHub-hosted runner. (`scripts/evaluate_asr_reference.py`, `.github/workflows`)
- Added a real-time 320 ms WAV replay through the packaged Parakeet/Nemotron library on Apple Silicon. The hosted proof records first-preview latency, P95 preview latency/backlog, finalization time, transcript loss/duplication and RSS growth. (`scripts/release_macos_parakeet_live_smoke.sh`, `apps/desktop/src-tauri/src/parakeet_realtime.rs`)
- Added pinned ASR/live evaluator fixtures as deterministic contract tests. They are explicitly synthetic self-tests and are never release evidence: a hosted packaged-engine harness must provide real ASR-reference and live-latency reports before candidate promotion can proceed. (`scripts/run_release_quality_gates.py`, `.github/workflows/release.yml`)
- Candidate promotion requires exactly the reviewed seven public JSON proof assets. Non-JSON installers, signatures, and `release-notes.md` remain allowed; any extra public JSON proof asset is rejected. (`scripts/promote_candidate_release.sh`)
- Reduced live waveform rendering overhead by batching microphone levels outside React's per-event render path. (`apps/desktop/src/components/LiveMicrophoneWaveform.tsx`)

### Compatibility

- Existing settings, models, transcripts, timelines, and API keys remain compatible. The former `compute_device` value continues to control file transcription; the new live preference defaults safely to Auto when absent.
- Candidate packages continue to target Apple Silicon macOS, Intel macOS, and Windows x86_64. CPU and Auto validation use standard public GitHub-hosted runners; no paid larger runner is required.

### Known issues

- Intel Metal acceleration is declared validated only when exercised on physical Intel Mac hardware. The public `macos-15-intel` gate validates the packaged Intel runtime in CPU and Auto modes without claiming unavailable GPU coverage.
- Parakeet/Nemotron live is enabled only on the validated Apple Silicon accelerated path. CPU live and x86 live fail immediately with an actionable choice to use Whisper live or preserve/transcribe the recording as a file, instead of silently accumulating an unusable backlog. Parakeet file transcription remains supported and is tested on Intel and Windows.

### Refs

- Release range: `v2.0.27..v2.0.28`.
- Evidence: the Intel hosted job produces the real long-file ASR/reference report and Pyannote deep smoke; the Apple Silicon hosted job produces the real packaged-engine live-latency report. Both are folded into the existing seven-proof promotion contract. Synthetic fixture reports remain contract tests only and cannot satisfy promotion.
