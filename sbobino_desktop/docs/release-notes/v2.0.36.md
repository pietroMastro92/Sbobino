## Sbobino 2.0.36

### Fixes

- Export Preview now moves keyboard focus into the dialog, keeps Tab and Shift+Tab inside it, and restores focus to Export when closed with Escape or after saving.
- General settings now expose accessible names for automatic update checks, Appearance and App Language.

### New and improved

- Keyboard navigation in Export Preview remains contained while an export is busy; disabled controls cannot close the operation.
- Targeted regressions cover accessible settings names and export focus without changing transcription engines or public APIs.

### Compatibility

- Existing settings, transcripts, models and compatible runtimes are preserved.
- Native installer targets remain macOS arm64, macOS Intel and Windows x86_64; Linux retains its declared frontend and crate validation scope.
- Live still requires the certified model and a successful device performance check.

### Known issues

- macOS packages are signed ad hoc and are not notarized; Windows installers remain unsigned. Updater artifacts use the configured updater signature.
- Spoken screen-reader announcements and full interactive Intel/Windows accessibility flows are not certified by hosted runners. The native ARM check covers accessible names, keyboard focus and TXT export in an isolated profile.
- This accessibility update does not establish a new transcription accuracy or performance improvement; prior engine benchmarks retain their own snapshots and limits.
