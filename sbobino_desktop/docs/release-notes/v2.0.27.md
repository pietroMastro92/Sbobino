## Sbobino 2.0.27

### Fixes

- Stabilized Whisper file transcription with bounded 15-second chunks, at most 16 inputs per process, preservation of completed outputs, isolated retry of missing chunks, and corrected global timestamps. (`crates/infrastructure/src/adapters/whisper_cpp.rs`)
- Stabilized Parakeet files longer than 45 seconds with the mandatory batch worker, bounded GPU retry windows, preservation of completed rows, and an Auto-to-CPU fallback that never returns to the unsafe whole-file CLI path. (`crates/infrastructure/src/adapters/parakeet_cpp.rs`)
- Kept transcription and saving available when AI is absent or misconfigured and when optional Pyannote diarization is unavailable. (`crates/infrastructure/src/lib.rs`)
- Made speech-runtime, model, CoreML, and Pyannote installation recoverable with staged downloads, checksums, atomic promotion, rollback journals, cancellation cleanup, and actionable failure diagnostics. (`apps/desktop/src-tauri/src/commands/provisioning.rs`)

### New and improved

- Added an explicit Auto/GPU/CPU setting for file and live Whisper/Parakeet. CPU mode now also applies to mandatory readiness probes, while GPU mode removes inherited force-CPU overrides. (`crates/domain/src/settings.rs`, `apps/desktop/src/App.tsx`, `apps/desktop/src-tauri/src/commands/runtime.rs`)
- Added bounded real readiness probes for FFmpeg decoding, Whisper transcription, the Parakeet batch worker, and local Pyannote pipeline loading; optional Pyannote failures no longer block ASR. (`apps/desktop/src-tauri/src/commands/runtime.rs`)
- Added version-specific release notes and gates that reject empty, generic, incomplete, or duplicated notes before candidate publication and promotion. (`docs/release-notes/v2.0.27.md`, `scripts/check_release_notes.sh`)

### Compatibility

- The public release continues to ship architecture-matched Apple Silicon (`aarch64-apple-darwin`), Intel macOS (`x86_64-apple-darwin`), and Windows (`x86_64-pc-windows-msvc`) installers, updater archives, and runtime assets.
- Existing Whisper/Parakeet model settings remain readable; `auto` is the default compute-device value and explicit `gpu`/`cpu` selection is accepted where the installed backend supports it.

### Known issues

- None known at candidate creation. Promotion to Latest remains conditional on the native Apple Silicon, Intel macOS, and Windows installer proofs passing.
