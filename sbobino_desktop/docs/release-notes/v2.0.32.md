## Sbobino 2.0.32

### Fixes

- Removed duplicate Parakeet preview inference for file transcription. Short files now load and run the model once instead of up to three times.
- Ensured timed-out Parakeet preview processes are terminated, preventing orphan native processes from accumulating CPU, GPU, and memory usage.
- Made the Parakeet thread setting effective for both direct file transcription and the long-file batch worker, capped at eight threads to preserve system responsiveness.
- Restricted TDT text-language classification to languages actually supported by both Parakeet TDT and Lingua 1.8. Maltese remains undetermined unless the ASR supplies a native label; unsupported languages are no longer guessed.
- Prevented the streaming-oriented Nemotron model from being selected for file transcription. Existing settings are durably migrated to multilingual TDT Q4, including automatic imports.
- Routed 15–45 second Parakeet files through the single-load batch worker so committed progress is emitted before completion without duplicate model inference.

### New and improved

- Added regression coverage proving that short Parakeet files do not launch duplicate preview inference, medium files report committed progress before worker exit, and the native worker applies the configured thread cap without changing the decoder.
- Validated the complete 9:41 local multilingual regression audio through the modified application worker with TDT Q4: successful persisted timeline, continuous intermediate progress, 90.76 seconds wall time, and about 0.79 GiB peak RSS on Apple M3.
- Kept every v2.0.31 Pyannote, Windows runtime, transactional installation, and hosted-proof correction unchanged.

### Compatibility

- Existing settings, transcripts, models, timelines, API keys, and compatible Pyannote installations remain readable.
- File transcription with Parakeet uses TDT Q4. Live transcription continues to use the separately validated Whisper live runtime.
- Candidate packages target Apple Silicon macOS, Intel macOS, and Windows x86_64 using the standard hosted release matrix.

### Known issues

- Lingua 1.8 has no Maltese classifier. TDT can transcribe Maltese, but the language badge remains undetermined unless the model output includes a language label.
- v2.0.31 remains a prerelease and was not promoted after real-device reports of Parakeet resource saturation and weaker file-model selection.
